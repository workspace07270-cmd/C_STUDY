# Day 20 - 정렬과 종합 프로젝트

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 버블·선택·삽입 정렬의 동작과 복잡도를 비교한다.
- 표준 `qsort`에 비교 함수를 전달한다.
- 앞선 자료형, 배열, 함수, 구조체 개념을 통합한다.

## 핵심

세 기본 정렬은 평균적으로 O(N²)이며 작은 자료와 알고리즘 학습에 적합합니다. 실무에서는 검증된 라이브러리를 우선합니다. `qsort` 비교 함수는 뺄셈으로 결과를 만들면 정수 오버플로가 날 수 있으므로 관계 비교를 사용하세요.

## 종합 과제

학생 이름과 점수를 입력받아 평균·최고점·등급을 계산하고 원하는 기준으로 정렬한 뒤 텍스트 파일에 저장하세요. 입력 검증, 함수 분리, 파일 오류 처리를 포함해야 합니다.

## 추가 연습문제

1. 삽입 정렬을 직접 구현하고 각 단계 배열을 출력하세요.
2. 이름 기준 비교 함수를 추가하세요.
3. 이진 탐색을 구현하고 정렬이 선행되어야 하는 이유를 설명하세요.
