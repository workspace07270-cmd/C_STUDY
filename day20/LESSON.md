# Day 20 상세 학습 - 정렬과 종합 프로그램 설계

## 학습 목표

기본 정렬 알고리즘을 추적하고 `qsort` 비교 함수를 작성한 뒤, 20일 동안 배운 개념을 성적 관리 프로그램으로 통합합니다.

## 1. 세 가지 기본 정렬

버블 정렬은 인접 원소를 비교하며 큰 값을 끝으로 이동시킵니다. 선택 정렬은 정렬되지 않은 구간의 최솟값을 찾아 앞에 놓습니다. 삽입 정렬은 새 값을 이미 정렬된 앞 구간의 알맞은 위치에 끼웁니다.

세 알고리즘은 일반적으로 O(N²) 비교가 필요합니다. 삽입 정렬은 거의 정렬된 작은 데이터에서 효율적일 수 있습니다. 알고리즘 학습에는 직접 구현하되 실제 프로그램에서는 검증된 라이브러리를 우선합니다.

## 2. qsort와 비교 함수

`qsort`는 원소 형식을 모르므로 `void *`와 원소 크기, 비교 콜백을 받습니다. 비교 함수는 왼쪽이 앞이면 음수, 같으면 0, 뒤면 양수를 반환합니다.

```c
return (a->score > b->score) - (a->score < b->score);
```

단순히 `a->score - b->score`를 반환하면 큰 정수에서 오버플로할 수 있습니다. 내림차순은 비교 방향을 바꿉니다. 동점일 때 이름 같은 두 번째 기준을 적용하면 결과가 안정적으로 보입니다.

## 3. 종합 프로젝트 분해

성적 관리 프로그램을 한 번에 작성하지 마세요. 다음 순서로 작게 완성합니다.

1. `Student` 구조체와 학생 한 명 출력
2. 동적 배열의 추가와 용량 확장
3. 이름 검색과 점수 통계
4. 비교 함수와 정렬
5. 메뉴 입력 검증
6. 파일 저장과 불러오기
7. 모든 종료 경로의 메모리 해제

각 단계가 동작하고 경고 없이 컴파일된 뒤 다음 단계로 이동합니다. 계산 함수에는 화면 입출력을 섞지 않으면 테스트가 쉬워집니다.

## 4. 테스트 설계

정상 데이터뿐 아니라 학생 0명·1명, 동점, 같은 이름, 점수 0·100, 잘못된 점수, 긴 이름, 존재하지 않는 파일, 손상된 파일, 메모리 할당 실패 가능성을 검토하세요. 테스트는 입력, 예상 결과, 실제 결과를 표로 남깁니다.
