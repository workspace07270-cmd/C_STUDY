# Day 20 문제

## 1. 기본 - 삽입 정렬

정수 배열을 오름차순으로 정렬하는 삽입 정렬을 구현하세요. 각 회차가 끝날 때 배열 상태를 출력합니다.

## 2. 응용 - 다중 기준 정렬

학생 구조체를 점수 내림차순으로 정렬하고 동점이면 이름 오름차순으로 정렬하는 `qsort` 비교 함수를 작성하세요.

## 3. 도전 - 성적 관리 프로젝트

학생 추가·검색·정렬·통계·파일 저장·불러오기 메뉴를 가진 프로그램을 작성하세요. 동적 배열, 안전한 문자열 입력, 함수 분리, 파일 오류 처리와 종료 시 메모리 해제를 모두 포함합니다.

### 완료 기준

- 컴파일 경고가 없다.
- 빈 데이터, 잘못된 메뉴, 중복 이름, 파일 없음 상황을 처리한다.
- 기능별 함수가 분리되어 있다.
- 최소 8개의 테스트 시나리오와 예상 결과를 문서화한다.
