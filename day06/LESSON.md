# Day 06 상세 학습 - 함수로 문제 나누기

## 학습 목표

큰 문제를 입력·계산·출력 책임으로 나누고 함수 선언, 정의, 호출, 반환값, 변수 범위를 이해합니다.

## 1. 함수의 계약

함수는 입력인 매개변수와 결과인 반환값으로 계약을 표현합니다. 이름은 동작을 드러내고 한 함수는 한 가지 책임에 집중해야 테스트하기 쉽습니다.

```c
static int maximum(int a, int b)
{
    return a > b ? a : b;
}
```

호출 시 `a`, `b`의 값이 매개변수로 복사됩니다. 함수 안에서 매개변수를 바꿔도 호출자 변수는 바뀌지 않습니다. `return`은 결과를 호출 지점에 돌려주고 함수를 즉시 끝냅니다.

## 2. 선언과 정의

함수 정의가 호출보다 뒤에 있으면 먼저 원형을 선언해야 합니다. 선언은 이름과 형식을 알리고 정의는 실제 동작을 제공합니다. 매개변수가 없음을 분명히 하려면 빈 괄호보다 `(void)`를 사용합니다.

## 3. 변수의 범위와 생명주기

블록 안 지역 변수는 해당 블록에서만 이름을 사용할 수 있고 블록 실행 중에만 존재합니다. 파일 범위의 `static` 함수는 현재 소스 파일에서만 보이므로 내부 구현을 감추는 데 좋습니다. 함수 안 `static` 지역 변수는 호출이 끝나도 값을 유지하지만 숨은 상태가 생기므로 필요한 경우에만 사용하세요.

## 4. 설계 순서

먼저 함수가 무엇을 받아 무엇을 돌려줄지 적습니다. 그다음 정상 입력, 경계값, 잘못된 입력을 정하고 구현합니다. 출력까지 함수 안에 섞기보다 계산 결과를 반환하면 재사용과 테스트가 쉬워집니다.

## 따라 하기

`maximum`을 이용해 세 수의 최댓값을 구하세요. `absolute_value`에 가장 작은 정수가 들어오면 단순 부호 반전이 표현 범위를 넘을 수 있다는 점도 조사하세요.

## 완료 기준

선언과 정의의 차이, 값 복사의 의미, 지역 변수와 `static`의 차이를 설명하고 20줄 이상의 계산을 2~3개 함수로 자연스럽게 나눌 수 있으면 완료입니다.
