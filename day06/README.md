# Day 06 - 함수와 변수 범위

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 선언, 정의, 호출을 구분한다.
- 매개변수와 반환값으로 기능을 분리한다.
- 지역 변수, 파일 범위, `static`의 생명주기를 이해한다.

## 핵심

함수는 한 가지 책임을 가지며 이름으로 의도를 드러냅니다. 전역 상태보다 매개변수와 반환값을 우선하세요. 호출 전에 함수 원형이 보여야 합니다.
