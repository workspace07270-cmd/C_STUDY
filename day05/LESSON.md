# Day 05 상세 학습 - 반복과 누적 패턴

## 학습 목표

반복 횟수와 종료 조건에 맞는 반복문을 선택하고, 합계·개수·최솟값·검색 같은 대표 패턴을 구현합니다.

## 1. for, while, do while

`for`는 초기화, 계속 조건, 증감을 한곳에 모으므로 횟수가 분명할 때 적합합니다. `while`은 입력이 특정 조건을 만족할 때까지처럼 횟수를 미리 모를 때 사용합니다. `do while`은 본문을 최소 한 번 실행해야 하는 메뉴에 유용합니다.

```c
for (int i = 0; i < count; ++i) {
    /* i는 0부터 count-1까지 */
}
```

반복 조건을 작성할 때 시작값, 마지막 유효값, 종료 직후 값을 차례로 확인하면 off-by-one 오류를 줄일 수 있습니다.

## 2. 누적과 개수 세기

합계는 반복 전 0으로 초기화하고 각 값을 더합니다. 조건에 맞는 값의 평균은 전체 개수가 아니라 실제로 더한 개수로 나눕니다.

```c
int even_count = 0;
long even_sum = 0;
if (value % 2 == 0) {
    even_sum += value;
    ++even_count;
}
```

평균 계산 전 `even_count != 0`인지 확인해야 합니다.

## 3. 최솟값과 최댓값

임의의 큰 숫자로 초기화하기보다 첫 입력값으로 초기화하고 두 번째부터 비교하는 방식이 안전합니다. 입력 개수가 0이면 첫 값 자체가 없으므로 사전에 거부합니다.

## 4. 중첩 반복과 종료

구구단이나 표는 반복문 안에 반복문을 둡니다. `break`는 가장 가까운 반복 하나만 끝내고 `continue`는 현재 회차의 나머지를 건너뜁니다. 남용하면 흐름을 추적하기 어려워집니다.

## 따라 하기

`main.c`를 실행해 개수 1, 여러 양수, 음수가 섞인 값, 개수 0, 중간 문자 입력을 시험하세요. 이후 평균과 함께 최솟값·최댓값을 출력하도록 확장하세요.

## 완료 기준

반복문의 불변 조건을 말로 설명하고, 0회·1회·여러 회 반복을 각각 검증하며, 조건에 맞는 값이 하나도 없는 상황을 처리할 수 있으면 완료입니다.
