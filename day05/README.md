# Day 05 - 반복문

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- `for`, `while`, `do while`을 상황에 맞게 선택한다.
- 누적, 개수 세기, 최솟값·최댓값 패턴을 익힌다.
- 반복 종료 조건과 무한 반복을 점검한다.

## 핵심

반복 횟수가 분명하면 `for`, 조건 중심이면 `while`이 자연스럽습니다. 평균은 합계뿐 아니라 유효한 값의 개수도 관리해야 합니다.

## 연습문제

1. 구구단 한 단을 출력하세요.
2. 입력한 수가 소수인지 판정하세요.
3. 1부터 N까지 3 또는 5의 배수 합을 구하세요.
