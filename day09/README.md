# Day 09 - 포인터 기초

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 값, 주소, 포인터의 관계를 설명한다.
- `&`와 `*` 연산자를 올바르게 사용한다.
- `NULL`과 유효하지 않은 포인터의 위험을 이해한다.

## 핵심

포인터는 특정 자료형 객체의 주소를 저장합니다. 초기화하지 않은 포인터나 수명이 끝난 객체의 주소를 역참조하면 안 됩니다. 주소 출력에는 `%p`와 `(void *)`를 사용합니다.

## 연습문제

1. `int`, `double`, `char` 변수의 주소를 출력하세요.
2. 포인터를 통해 값을 2배로 바꾸는 함수를 작성하세요.
3. `NULL` 검사 전후의 흐름을 설명하세요.
