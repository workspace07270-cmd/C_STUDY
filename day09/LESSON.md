# Day 09 상세 학습 - 주소와 포인터

## 학습 목표

객체의 값과 주소를 구분하고 포인터 선언, 주소 저장, 역참조, `NULL` 검사를 안전하게 수행합니다.

## 1. 포인터의 의미

```c
int value = 42;
int *pointer = &value;
```

`value`는 정수를 저장하고 `&value`는 그 객체가 위치한 주소입니다. `pointer`는 `int` 객체의 주소를 저장합니다. `*pointer`는 그 주소에 있는 `int` 객체를 뜻하며 읽거나 수정할 수 있습니다.

선언의 `*`는 포인터 자료형을 만들고 식의 `*`는 역참조 연산입니다. 같은 기호지만 문맥이 다릅니다.

## 2. 포인터 자료형이 필요한 이유

컴파일러는 `int *`를 역참조할 때 `int` 크기와 해석 방법을 사용합니다. 서로 맞지 않는 포인터 형식을 억지로 변환하면 정렬과 표현 문제로 잘못된 동작이 생길 수 있습니다.

## 3. NULL과 유효성

`NULL`은 어떤 객체도 가리키지 않는다는 표시입니다. 역참조 전에 검사할 수 있지만, `NULL`이 아니라고 항상 유효한 것은 아닙니다. 초기화하지 않은 포인터, 수명이 끝난 지역 변수의 주소, 해제된 메모리의 주소도 역참조하면 안 됩니다.

```c
if (pointer != NULL) {
    printf("%d\n", *pointer);
}
```

주소는 `printf("%p", (void *)pointer)`로 출력합니다. 실행할 때마다 주소가 달라질 수 있으므로 특정 숫자를 외우지 마세요.

## 4. 그림으로 추적하기

종이에 `value` 상자와 `pointer` 상자를 그리고 pointer 안에는 value 상자를 향하는 화살표를 그리세요. `*pointer = 100`은 pointer 자체를 바꾸는 것이 아니라 화살표 끝의 value를 바꿉니다.

## 완료 기준

`pointer`, `&pointer`, `*pointer`가 각각 무엇인지 설명하고 초기화되지 않은 포인터가 위험한 이유를 말할 수 있으면 완료입니다.
