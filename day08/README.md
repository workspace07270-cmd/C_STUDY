# Day 08 - 다차원 배열

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 행과 열로 구성된 데이터를 모델링한다.
- 중첩 반복문으로 행별·열별 통계를 계산한다.
- 함수에 2차원 배열을 전달할 때 열 크기가 필요한 이유를 안다.

## 핵심

`int scores[3][4]`는 3행 4열이며 메모리에 행 우선으로 연속 저장됩니다. 각 반복문의 경계를 행과 열 크기에 맞추세요.

## 연습문제

1. 행렬의 전치 결과를 출력하세요.
2. 두 행렬을 더하세요.
3. 학생별 평균과 과목별 평균을 모두 구하세요.
