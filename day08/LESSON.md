# Day 08 상세 학습 - 표와 행렬을 다차원 배열로 표현하기

## 학습 목표

행·열 구조를 2차원 배열로 모델링하고 중첩 반복문으로 행별·열별 계산을 수행합니다.

## 1. 메모리와 인덱스

```c
int scores[3][4];
```

3명의 학생과 4과목 점수처럼 해석할 수 있습니다. 첫 인덱스는 행 0~2, 두 번째는 열 0~3입니다. C는 각 행의 원소를 연속해서 저장하는 행 우선 방식을 사용합니다.

## 2. 중첩 반복문

바깥 반복은 행을 선택하고 안쪽 반복은 해당 행의 모든 열을 방문합니다. 행 합계는 새 행을 시작할 때 0으로 다시 초기화해야 합니다.

```c
for (size_t row = 0; row < ROWS; ++row) {
    int row_sum = 0;
    for (size_t col = 0; col < COLS; ++col) {
        row_sum += matrix[row][col];
    }
}
```

열 합계는 열을 바깥 반복으로 두거나 열별 합계 배열을 유지할 수 있습니다.

## 3. 함수에 전달하기

`void print(int rows[][COLS], size_t row_count)`처럼 뒤쪽 차원의 크기를 컴파일러가 알아야 다음 행의 주소를 계산할 수 있습니다. C99의 가변 길이 배열을 쓸 수도 있지만 이 과정에서는 상수 열 크기와 명시적 행 개수부터 익힙니다.

## 4. 행렬 계산

행렬 덧셈은 같은 위치끼리 더합니다. 곱셈에서는 왼쪽 행과 오른쪽 열의 대응 원소 곱을 누적합니다. 차원이 맞지 않으면 연산 자체를 정의할 수 없으므로 종이에 크기를 먼저 적으세요.

## 따라 하기와 완료 기준
