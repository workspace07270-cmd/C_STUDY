# Day 14 상세 학습 - 필요한 만큼 메모리 관리하기

## 학습 목표

힙 메모리를 할당·확장·해제하고, 실패 처리와 소유권 규칙으로 누수와 잘못된 접근을 방지합니다.

## 1. 자동 저장 공간과 동적 저장 공간

지역 배열은 블록을 벗어나면 수명이 끝나고 크기를 설계 시 정하는 경우가 많습니다. 동적 메모리는 실행 중 필요한 크기를 정하고 `free`할 때까지 유지할 수 있습니다. 대신 프로그래머가 수명을 책임집니다.

```c
int *values = malloc(count * sizeof *values);
if (values == NULL) {
    /* 할당 실패 */
}
```

C에서는 `malloc`의 `void *`가 객체 포인터로 자동 변환되므로 캐스팅하지 않습니다. `sizeof *values`를 쓰면 포인터 자료형을 바꿔도 원소 크기 식이 따라갑니다.

## 2. 크기와 오버플로

`count * sizeof *values`가 `size_t` 범위를 넘으면 실제보다 작은 메모리가 할당될 수 있습니다. 외부 입력으로 매우 큰 개수를 허용하지 말고 필요하면 `count > SIZE_MAX / sizeof *values`를 검사합니다.

## 3. realloc 안전 패턴

`realloc`은 같은 주소를 확장하거나 새 블록으로 옮길 수 있고 실패하면 원래 블록은 그대로 유지됩니다.

```c
int *temporary = realloc(values, new_count * sizeof *values);
if (temporary != NULL) values = temporary;
```

결과를 원래 포인터에 즉시 대입하면 실패 시 기존 주소를 잃어 메모리 누수가 발생합니다.

## 4. 소유권 규칙

할당한 메모리는 정확히 한 번 해제합니다. `free` 후에는 포인터를 역참조하지 말고 필요하면 `NULL`로 바꿉니다. 다른 함수에 포인터를 넘길 때 어느 쪽이 해제하는지 계약을 정하세요.

## 완료 기준

할당 실패, 이중 해제, use-after-free, 메모리 누수를 각각 설명하고 모든 종료 경로에서 메모리가 해제되는 코드를 작성하면 완료입니다.
