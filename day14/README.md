# Day 14 - 동적 메모리

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- `malloc`, `realloc`, `free`의 책임을 이해한다.
- 할당 실패와 크기 계산 오류를 처리한다.
- 소유권과 객체 수명을 추적한다.

## 핵심

C에서는 `malloc` 반환값을 캐스팅할 필요가 없습니다. `realloc`은 임시 포인터로 받은 뒤 성공했을 때 원래 포인터를 갱신하세요. 할당한 메모리는 정확히 한 번 해제합니다.

## 연습문제

1. N개의 실수 평균을 동적 배열로 계산하세요.
2. 용량이 두 배씩 증가하는 정수 목록을 구현하세요.
3. 2차원 동적 배열을 만들고 완전히 해제하세요.
