# Day 19 - 이진 파일과 직렬화

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- `fread`와 `fwrite`의 항목 수를 검사한다.
- 텍스트 파일과 이진 파일을 비교한다.
- 구조체 메모리를 그대로 저장하는 방식의 한계를 이해한다.

## 핵심

구조체를 그대로 저장한 파일은 패딩, 엔디언, 자료형 크기 때문에 다른 컴파일러나 시스템에서 호환되지 않을 수 있습니다. 장기 보관 형식은 필드별 고정 형식과 버전 정보를 설계하세요.

## 연습문제

1. 레코드 여러 개를 저장하고 읽으세요.
2. 파일 머리말에 형식 버전과 레코드 수를 넣으세요.
3. 손상되거나 짧은 파일을 감지하세요.
