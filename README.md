# 현대 표준 C 20일 완성 과정

기존 강의안을 C17 기준으로 다듬은 실습형 커리큘럼입니다. 각 폴더에서 `README.md`로 목표를 확인하고, `LESSON.md`로 개념을 학습하고, `main.c`를 실행한 다음, `PROBLEMS.md`의 기본·응용·도전 문제를 해결합니다.

## 컴파일

각 일차 폴더에서 다음 명령을 실행합니다.

```powershell
gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o main.exe
./main.exe
```

전체 예제를 한 번에 검사하려면 GCC 설치 후 커리큘럼 루트에서 실행합니다.

```powershell
./check-all.ps1
```

입력이 있는 예제는 잘못된 입력을 감지하며, `main`은 표준 형식인 `int main(void)`를 사용합니다.

## 권장 학습 루틴

1. `README.md`에서 목표와 선수 지식을 확인합니다.
2. `LESSON.md`를 읽고 확인 질문에 말이나 글로 답합니다.
3. `main.c`의 결과를 예상한 뒤 컴파일하고 한 줄씩 추적합니다.
4. 예제를 보지 않고 다시 작성합니다.
5. `PROBLEMS.md`의 문제를 최소 2개 해결합니다.
6. 경고 없이 컴파일되고 학습 완료 기준을 만족하는지 확인합니다.

문제 풀이는 일차별로 `solutions/problem1.c`, `solutions/problem2.c`, `solutions/problem3.c`처럼 저장하는 것을 권장합니다. 정답 코드는 제공하지 않으므로 먼저 스스로 설계하고 경계값까지 직접 테스트하세요.
