# Day 16 - 열거형과 상태 모델링

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 관련된 정수 상수에 의미 있는 이름을 붙인다.
- 열거형과 `switch`로 상태 전이를 표현한다.
- 유효하지 않은 열거값도 방어적으로 처리한다.

## 핵심

열거형은 가능한 상태를 코드에 드러내 가독성을 높입니다. C의 열거값은 런타임에 완전히 제한되지 않으므로 `default` 처리도 고려하세요.

## 연습문제

1. 신호등 상태와 다음 상태 함수를 작성하세요.
2. 주문 처리 상태 전이를 모델링하세요.
3. 요일 열거형을 문자열로 바꾸세요.
