# Day 01 - C 프로그램의 구조와 도구

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 소스 코드, 컴파일, 링크, 실행의 관계를 설명한다.
- 헤더와 `main` 함수의 역할을 이해한다.
- 컴파일 경고를 읽는 습관을 만든다.

## 핵심

프로그램은 `main`에서 시작하며 성공 시 `0`을 반환합니다. `#include <stdio.h>`는 `printf`의 선언을 가져옵니다. C는 대소문자를 구분하고 문장 끝에 세미콜론을 사용합니다.

## 실습

예제의 이름과 학습 목표를 자신의 정보로 바꿔 출력하세요. 이후 세미콜론 하나를 제거해 컴파일러 오류의 위치와 원인을 관찰하세요.

## 연습문제

1. 세 줄짜리 자기소개를 출력하세요.
2. `\n`과 `\t`의 출력 차이를 확인하세요.
3. 경고 옵션을 뺀 경우와 넣은 경우를 비교하세요.
