# Day 01 상세 학습 - C 프로그램은 어떻게 실행되는가

## 학습 준비

오늘은 프로그래밍 경험이 없어도 됩니다. 텍스트 파일을 저장하고 터미널에서 현재 폴더를 이동하는 방법만 익히면 됩니다. 목표 학습 시간은 개념 40분, 실습 50분, 문제 풀이 40분입니다.

## 1. 소스 코드에서 실행 파일까지

C 소스 파일은 사람이 읽는 텍스트이며 보통 `.c` 확장자를 사용합니다. 컴파일러는 문법과 자료형을 검사해 기계어가 담긴 목적 파일을 만들고, 링커는 표준 라이브러리 코드와 목적 파일을 묶어 실행 파일을 만듭니다. 일상적으로 “컴파일한다”는 표현은 이 전체 과정을 뜻하기도 합니다.

```text
main.c → 전처리 → 컴파일 → 목적 파일 → 링크 → 실행 파일
```

컴파일 오류는 실행 파일을 만들 수 없는 문제이고, 경고는 만들 수 있지만 의심스러운 코드입니다. 학습 단계에서는 경고도 오류처럼 다루세요.

## 2. 첫 프로그램 해부

```c
#include <stdio.h>

int main(void)
{
    printf("Hello\n");
    return 0;
}
```

`#include`는 전처리 지시문입니다. `stdio.h`에 선언된 `printf`를 올바른 형식으로 호출하게 합니다. `main`은 운영체제가 프로그램을 시작할 때 호출하는 함수입니다. `void`는 명령행 인수를 받지 않는다는 뜻이고 `int`는 종료 상태를 반환한다는 뜻입니다. 0은 성공, 0이 아닌 값은 실패를 관례적으로 나타냅니다.

문자열은 큰따옴표로 감싸고 `\n`은 개행 문자입니다. C 문장은 대부분 세미콜론으로 끝나며 중괄호는 코드 블록의 범위를 만듭니다.

## 3. 직접 실행하고 관찰하기

`main.c`가 있는 폴더에서 다음을 실행하세요.

```powershell
gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o main.exe
./main.exe
$LASTEXITCODE
```

문자열을 바꾸고 다시 컴파일해야 실행 파일에 변경이 반영됩니다. 소스만 저장하고 이전 실행 파일을 실행하는 실수를 주의하세요.

## 흔한 실수

- `stdio.h`를 빼고 `printf`를 호출한다.
- `main`을 `void main`으로 작성한다. 표준 형식이 아니다.
- 한글 따옴표나 전각 세미콜론을 붙여 넣는다.
- 오류 메시지의 첫 번째 오류를 무시한다. 뒤 오류는 연쇄적으로 발생할 수 있다.
