# Day 12 - 함수 포인터와 `void *`

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 함수의 주소를 저장하고 간접 호출한다.
- 콜백 패턴의 용도를 이해한다.
- `void *` 변환 시 실제 객체 자료형을 잃지 않는다.

## 핵심

함수 포인터 형식은 반환형과 매개변수 형식이 일치해야 합니다. `void *`는 범용 객체 포인터지만 역참조하기 전에 올바른 자료형으로 변환해야 합니다.

## 연습문제

1. 사칙연산 함수 테이블을 만드세요.
2. 배열의 각 원소에 콜백을 적용하세요.
3. 비교 함수를 교체해 오름차순·내림차순을 선택하세요.
