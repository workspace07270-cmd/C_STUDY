# Day 04 상세 학습 - 조건에 따라 흐름 선택하기

## 학습 목표

조건의 참·거짓에 따라 실행 경로를 나누고 모든 입력 범위와 경계값을 처리합니다. `if` 계열과 `switch`의 선택 기준도 익힙니다.

## 1. if 문

`if`는 조건이 참일 때 블록을 실행합니다. `else if`는 앞 조건이 거짓일 때 다음 조건을 검사하고 `else`는 어느 조건에도 해당하지 않는 경우를 처리합니다.

```c
if (score >= 90) grade = 'A';
else if (score >= 80) grade = 'B';
else grade = 'F';
```

높은 점수부터 검사하기 때문에 두 번째 조건에 도달한 점수는 이미 90 미만입니다. 조건 순서를 반대로 쓰면 95점도 `score >= 80`에서 먼저 잡힙니다.

## 2. 입력 범위와 경계값

분기 전에 유효 범위를 검사하면 핵심 로직이 단순해집니다. 점수에서는 -1, 0, 59, 60, 89, 90, 100, 101 같은 경계 주변 값을 테스트하세요. 정상값 하나만 시험해서는 조건 누락을 찾기 어렵습니다.

## 3. switch 문

`switch`는 하나의 정수형 식이 여러 정확한 값 중 어디에 해당하는지 나눌 때 적합합니다.

```c
switch (menu) {
    case 1: puts("추가"); break;
    case 2: puts("조회"); break;
    default: puts("잘못된 메뉴"); break;
}
```

`break`가 없으면 다음 case까지 계속 실행됩니다. 의도적 fall-through가 아니라면 반드시 종료하세요. 점수 범위처럼 부등식 중심인 문제는 `if`가 더 자연스럽습니다.

## 4. 조건 연산자

`조건 ? 참일_때_값 : 거짓일_때_값`은 값 하나를 선택하는 짧은 식에 적합합니다. 여러 단계로 중첩하면 읽기 어려워지므로 복잡한 흐름은 `if`로 작성하세요.

## 실습과 확인

성적 예제에 합격 여부를 추가하고 정확히 100점이면 별도 메시지를 출력하세요. 입력 `-1`, `59`, `60`, `100`, `101`, `abc`의 예상 결과를 먼저 표로 만든 뒤 실행하세요.

조건이 겹치지 않는지, 가능한 모든 입력 경로에 결과가 있는지 스스로 검사할 수 있으면 완료입니다.
