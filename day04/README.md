# Day 04 - 조건문

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- `if`, `else if`, `else`로 범위를 분기한다.
- `switch`가 적합한 경우를 구분한다.
- 경계값을 빠뜨리지 않는다.

## 핵심

조건은 가장 구체적인 경우부터 검사하고 모든 입력 범위를 다룹니다. `=`과 `==`을 혼동하지 마세요. `switch`의 각 `case`는 의도적인 경우를 제외하고 `break`로 끝냅니다.

## 연습문제

1. 세 수의 최댓값을 구하세요.
2. 월을 입력받아 계절을 출력하세요.
3. BMI 범주 판정기를 작성하세요.
