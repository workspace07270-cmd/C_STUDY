# Day 18 - 텍스트 파일 입출력

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 파일 열기, 처리, 닫기의 생명주기를 지킨다.
- `fopen` 실패와 읽기 오류를 구분한다.
- 텍스트 형식의 장단점을 설명한다.

## 핵심

상대 경로를 사용하면 실행 위치를 기준으로 파일이 만들어집니다. 쓰기 후 `fclose` 결과도 중요한 데이터라면 확인해야 합니다. `feof`를 읽기 조건으로 사용하지 말고 실제 읽기 함수의 반환값을 검사하세요.

## 연습문제

1. 입력 문장을 여러 줄 저장하세요.
2. 파일의 줄·단어·문자 수를 계산하세요.
3. 원본을 다른 파일로 복사하며 줄 번호를 붙이세요.
