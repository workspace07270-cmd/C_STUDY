# Day 10 상세 학습 - 배열과 포인터의 관계

## 학습 목표

배열 이름의 포인터 변환, 포인터 산술, 배열 처리 함수, `const` 정확성을 이해합니다.

## 1. 배열 이름의 변환

대부분의 식에서 배열 이름은 첫 원소를 가리키는 포인터로 변환됩니다. 따라서 아래 두 식은 같은 원소를 나타냅니다.

```c
values[i]
*(values + i)
```

포인터에 1을 더하면 주소 숫자 1이 아니라 가리키는 자료형 원소 하나만큼 이동합니다. `int *p`의 `p + 1`은 다음 int를 가리킵니다.

## 2. 배열과 포인터는 동일하지 않다

관련은 깊지만 배열 자체와 포인터 변수는 다른 객체입니다. 배열은 고정된 원소 저장 공간이고 배열 이름에 새 주소를 대입할 수 없습니다. `sizeof array`는 전체 배열 크기지만 `sizeof pointer`는 주소 하나의 크기입니다.

## 3. 함수 매개변수

```c
int sum_array(const int *values, size_t count);
```

함수는 첫 원소 주소만으로 배열 끝을 알 수 없으므로 `count`가 필요합니다. 읽기만 하는 포인터에는 `const`를 붙이면 호출자 데이터가 변경되지 않는다는 계약을 컴파일러가 검사합니다.

## 4. 유효한 포인터 산술 범위

같은 배열 내부와 마지막 원소 바로 다음 주소까지 포인터를 이동·비교할 수 있습니다. 끝 다음 포인터는 반복 종료 비교에는 쓸 수 있지만 역참조하면 안 됩니다.

```c
for (const int *p = values; p != values + count; ++p) {
    sum += *p;
}
```

## 따라 하기와 완료 기준

인덱스 방식과 포인터 방식으로 같은 배열을 출력하고 결과를 비교하세요. `sizeof`를 배열이 있는 `main`과 포인터 매개변수 함수 안에서 각각 출력해 차이를 설명할 수 있으면 완료입니다.
