# Day 10 - 포인터와 배열

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 배열 이름이 표현식에서 첫 원소 포인터로 변환됨을 이해한다.
- 포인터 산술과 인덱싱의 관계를 설명한다.
- `const`로 읽기 전용 의도를 표현한다.

## 핵심

`array[i]`는 `*(array + i)`와 같은 의미입니다. 함수 매개변수에서는 배열 길이 정보가 사라지므로 길이를 함께 전달합니다.

## 연습문제

1. 포인터만 사용해 배열을 역순 출력하세요.
2. 배열에서 목표값의 주소를 반환하는 함수를 작성하세요.
3. 배열의 양수만 합산하는 함수를 작성하세요.
