# Day 07 - 1차원 배열

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 같은 자료형의 연속된 데이터를 배열로 다룬다.
- 유효 인덱스 범위를 지킨다.
- 배열 길이를 별도로 전달해야 하는 이유를 이해한다.

## 핵심

길이가 N인 배열의 인덱스는 0부터 N-1입니다. 범위를 벗어난 접근은 정의되지 않은 동작입니다. 배열 전체의 바이트 크기는 선언된 범위에서만 `sizeof array`로 구할 수 있습니다.

## 연습문제

1. 배열을 역순으로 출력하세요.
2. 중복을 제외한 값만 출력하세요.
3. 두 번째로 큰 값을 구하세요.
