# Day 07 상세 학습 - 1차원 배열로 여러 값 다루기

## 학습 목표

같은 자료형의 여러 값을 연속된 메모리에 저장하고 반복문으로 안전하게 처리합니다.

## 1. 선언, 초기화, 인덱스

```c
int values[5] = {10, 20, 30, 40, 50};
```

배열 길이는 5이고 유효 인덱스는 0~4입니다. `values[5]` 접근은 컴파일될 수 있지만 배열 밖 메모리를 읽거나 써서 정의되지 않은 동작을 만듭니다. 일부 초기값만 쓰면 나머지는 0으로 초기화됩니다.

## 2. 길이 계산

배열이 실제 배열로 보이는 범위에서는 다음 식으로 원소 수를 구할 수 있습니다.

```c
size_t count = sizeof values / sizeof values[0];
```

하지만 함수 매개변수 `int values[]`는 실제로 포인터로 조정되므로 같은 식을 함수 안에서 사용하면 포인터 크기를 계산합니다. 따라서 함수에는 배열과 길이를 함께 전달합니다.

## 3. 대표 처리 패턴

합계는 0부터 누적합니다. 최솟값과 최댓값은 원소가 하나 이상임을 확인한 뒤 첫 원소로 초기화합니다. 검색은 찾은 인덱스를 반환하고 찾지 못한 상태를 `-1` 같은 별도 값으로 표현할 수 있습니다.

배열을 수정하지 않는 함수는 `const int values[]`로 선언해 의도를 알리고 실수로 변경하는 것을 막습니다.

## 4. 자료형과 오버플로

많은 `int` 값을 더하면 합계가 `int` 범위를 넘을 수 있으므로 더 넓은 `long long`을 고려합니다. 평균 계산은 `(double)sum / count`로 실수 나눗셈을 보장합니다.

## 따라 하기

현재 예제의 `VALUE_COUNT`를 1, 5, 10으로 바꾸고 입력 개수와 반복 경계가 일치하는지 확인하세요. 최댓값이 첫 번째·중간·마지막에 있는 세 사례도 시험하세요.

## 완료 기준

길이 N일 때 마지막 인덱스를 즉시 답하고, 빈 배열을 받을 수 있는 함수의 계약을 정하며, 배열과 길이를 함께 전달하는 이유를 설명하면 완료입니다.
