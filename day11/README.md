# Day 11 - 값 전달과 주소 전달

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- C의 인수 전달이 항상 값 복사임을 이해한다.
- 포인터 매개변수로 호출자 객체를 변경한다.
- 출력 매개변수의 성공 여부를 반환값으로 알린다.

## 핵심

흔히 Call by Reference라고 부르는 패턴도 실제로는 주소값을 복사해 전달하는 방식입니다. 포인터 인수는 `NULL`일 수 있는지 계약을 정하고 검사하세요.

## 연습문제

1. 두 `double` 값을 교환하세요.
2. 몫과 나머지를 출력 매개변수로 반환하세요.
3. 배열의 최솟값과 최댓값을 한 번에 구하세요.
