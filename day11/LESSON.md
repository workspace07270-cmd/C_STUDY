# Day 11 상세 학습 - 값 전달과 출력 매개변수

## 학습 목표

C의 함수 호출은 항상 값을 복사한다는 사실을 바탕으로, 포인터를 전달해 호출자 객체를 안전하게 수정합니다.

## 1. 값 전달

`void change(int value)`에 변수를 넘기면 변수의 현재 값이 매개변수에 복사됩니다. 함수가 매개변수를 바꿔도 원본은 그대로입니다. 큰 구조체는 복사 비용도 고려하지만 먼저 의미를 정확히 이해하세요.

## 2. 주소값 전달

호출자가 `&number`를 전달하면 함수는 그 주소값의 복사본을 받습니다. 복사된 포인터도 같은 원본 객체를 가리키므로 `*pointer`를 통해 원본을 수정할 수 있습니다. 흔히 Call by Reference라고 부르지만 C 언어 자체의 전달 방식은 여전히 값 전달입니다.

```c
int try_divide(int a, int b, int *quotient)
{
    if (b == 0 || quotient == NULL) return 0;
    *quotient = a / b;
    return 1;
}
```

반환값은 성공 여부에, 포인터 매개변수는 계산 결과에 사용할 수 있습니다. 실패했을 때 출력 매개변수를 변경할지 여부도 함수 계약에 적어야 합니다.

## 3. swap 추적

교환 함수에는 두 원본 주소가 들어옵니다. 첫 값을 임시 변수에 보존하고, 두 번째를 첫 번째에 저장한 뒤 임시 값을 두 번째에 저장합니다. 임시 변수 없이 순서대로 대입하면 한 값을 잃습니다.

## 4. 방어적 설계

포인터가 필수라면 문서로 명시하고 필요 시 `NULL`을 검사합니다. 두 포인터가 같은 객체를 가리키는 경우도 생각하세요. `swap_int(&a, &a)`는 안전하게 같은 값을 유지해야 합니다.

## 완료 기준

값 전달만으로 원본을 바꿀 수 없는 이유를 그림으로 설명하고 성공 여부와 여러 결과를 함께 돌려주는 함수를 작성할 수 있으면 완료입니다.
