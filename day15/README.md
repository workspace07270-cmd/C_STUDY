# Day 15 - 전처리기와 모듈화

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- `#include`, `#define`, 조건부 컴파일의 처리 시점을 이해한다.
- 매크로의 부작용을 피한다.
- 선언은 헤더, 구현은 소스 파일로 분리하는 원칙을 익힌다.

## 핵심

상수에는 가능하면 `const`나 `enum`을 사용합니다. 함수형 매크로는 인수와 전체 식을 괄호로 감싸도 인수가 여러 번 평가될 수 있으므로 짧은 함수가 더 안전할 수 있습니다. 헤더에는 include guard를 둡니다.
