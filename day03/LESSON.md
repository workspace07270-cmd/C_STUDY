# Day 03 상세 학습 - 연산자와 식 평가

## 학습 목표

산술, 비교, 논리, 대입 연산자를 조합해 의도를 정확히 표현합니다. 특히 정수 나눗셈, 0으로 나누기, 우선순위와 단락 평가를 이해해야 합니다.

## 1. 산술 연산자

`+`, `-`, `*`, `/`, `%`는 사칙연산과 나머지를 계산합니다. `%`는 정수 피연산자에 사용합니다. 정수 나눗셈은 0 방향으로 소수부를 버리며, 나누는 수가 0이면 실행 결과가 정의되지 않습니다.

```c
if (right != 0) {
    printf("%d %d\n", left / right, left % right);
}
```

`++value`는 먼저 증가 후 값을 사용하고 `value++`는 기존 값을 사용한 뒤 증가합니다. 한 식에서 같은 변수를 여러 번 변경하는 복잡한 코드는 피하세요.

## 2. 비교와 논리 연산

비교 연산 `== != < <= > >=`의 결과는 참이면 1, 거짓이면 0입니다. 논리곱 `&&`는 둘 다 참, 논리합 `||`는 하나 이상 참, `!`는 참과 거짓을 뒤집습니다.

```c
int valid = age >= 0 && age <= 130;
```

`&&`의 왼쪽이 거짓이면 오른쪽은 평가하지 않고, `||`의 왼쪽이 참이면 오른쪽은 평가하지 않습니다. 이를 단락 평가라고 하며 포인터 검사나 0 나눗셈 방지에 유용합니다.

## 3. 우선순위와 괄호

곱셈은 덧셈보다 먼저지만 기억에만 의존하지 마세요. `average = (a + b) / 2.0;`처럼 계산 단위를 괄호로 표현하면 읽는 사람과 컴파일러 모두 의도를 분명히 알 수 있습니다.

대입 `=`과 비교 `==`는 전혀 다릅니다. `if (value = 3)`은 값을 대입한 뒤 3을 참으로 판단하므로 컴파일 경고를 주의하세요.
