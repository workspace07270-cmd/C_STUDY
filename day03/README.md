# Day 03 - 연산자와 표현식

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 산술·관계·논리 연산자를 구분한다.
- 정수 나눗셈과 나머지의 특성을 이해한다.
- 연산자 우선순위에 의존하지 않고 괄호로 의도를 표현한다.

## 핵심

정수끼리의 `/`는 소수부를 버립니다. 나눗셈과 나머지 연산 전에는 0인지 확인합니다. `&&`와 `||`는 단락 평가를 수행합니다.

## 연습문제

1. 두 정수의 몫과 나머지를 출력하세요.
2. 윤년 판정식을 논리 연산자로 작성하세요.
3. 금액을 최소 동전 개수로 분해하세요.
