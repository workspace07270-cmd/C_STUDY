# Day 17 상세 학습 - 널 종료 문자열을 안전하게 다루기

## 학습 목표

C 문자열의 메모리 표현을 이해하고 길이 제한 입력, 탐색, 비교, 복사, 토큰화를 버퍼 범위 안에서 수행합니다.

## 1. 문자열의 실체

```c
char word[] = "C language";
```

문자열은 마지막에 값 0인 널 문자 `\0`가 붙은 `char` 배열입니다. `strlen`은 널 문자 전까지의 문자 수를 세므로 배열 전체 크기와 다릅니다. 널 문자가 없으면 문자열 함수가 배열 밖을 계속 읽습니다.

## 2. 한 줄 입력

`fgets(buffer, sizeof buffer, stdin)`은 최대 크기를 알 수 있어 `%s`보다 안전하고 공백도 읽습니다. 공간이 있으면 개행까지 저장하므로 다음처럼 제거합니다.

```c
buffer[strcspn(buffer, "\n")] = '\0';
```

버퍼가 가득 차 개행을 읽지 못한 경우 입력 스트림에 나머지가 남습니다. 긴 입력을 거부할지 여러 번 이어 읽을지 정책을 정해야 합니다.

## 3. 비교와 탐색

문자열은 배열이므로 `==`가 내용이 아니라 주소를 비교합니다. 내용 비교에는 `strcmp`를 쓰며 같을 때 0입니다. `strchr`와 `strstr`는 찾은 위치의 포인터 또는 실패 시 `NULL`을 반환하므로 역참조 전 검사합니다.

## 4. 복사와 이어 붙이기

목적지에는 내용과 마지막 널 문자까지 들어갈 공간이 있어야 합니다. 원본 길이가 목적지 용량보다 짧은지 확인하세요. `strncpy`는 항상 널 종료를 보장하는 안전 함수가 아니므로 의미를 정확히 알고 사용해야 합니다.

## 5. 문자 분류

`isalpha`, `isdigit`, `tolower`에는 음수가 아닌 `unsigned char` 값 또는 EOF를 전달해야 합니다. 일반 `char`가 음수가 될 수 있으므로 `(unsigned char)buffer[i]`로 변환합니다.

## 완료 기준

배열 크기·문자열 길이·남은 용량을 구분하고, 공백과 긴 입력을 처리하며, 모든 탐색 결과의 `NULL` 여부를 검사하면 완료입니다.
