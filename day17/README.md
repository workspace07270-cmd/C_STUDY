# Day 17 - 문자열

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 문자열이 널 문자로 끝나는 `char` 배열임을 이해한다.
- `fgets`, `strlen`, `strcmp`, `strchr`를 안전하게 사용한다.
- 버퍼 크기와 문자열 길이를 구분한다.

## 핵심

크기 제한 없는 문자열 입력은 피합니다. `fgets`는 개행도 저장할 수 있어 제거 과정이 필요합니다. 복사·이어 붙이기 전에는 목적지의 남은 공간을 계산하세요.

## 연습문제

1. 문장의 단어 수를 세세요.
2. 대소문자를 무시한 회문 판정기를 작성하세요.
3. 특정 문자의 모든 위치를 출력하세요.
