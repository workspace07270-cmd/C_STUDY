# Day 02 - 변수, 자료형, 표준 입출력

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- `int`, `double`, `char`의 용도를 구분한다.
- 초기화와 형 변환을 이해한다.
- `scanf`의 반환값으로 입력 성공 여부를 검사한다.

## 핵심

자료형은 값의 표현 범위와 연산 방식을 결정합니다. `scanf`에는 변수의 주소를 전달하며, 입력 항목 수와 반환값이 같은지 확인해야 합니다. 실수 출력은 필요한 정밀도를 명시하세요.

## 실습 및 연습문제

예제는 섭씨를 화씨로 변환합니다. 반대 방향 변환, 원의 넓이, 초를 시·분·초로 바꾸는 프로그램을 작성하세요.
