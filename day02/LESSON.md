# Day 02 상세 학습 - 값을 저장하고 입력받기

## 선수 지식과 목표

Day 01의 컴파일 과정을 이해해야 합니다. 오늘은 변수의 선언·초기화, 기본 자료형, 서식 지정자, 입력 검사를 익힙니다. 예상 시간은 2시간 30분입니다.

## 1. 변수와 자료형

변수는 이름이 붙은 저장 공간입니다. 선언은 컴파일러에 자료형과 이름을 알려주며 초기화는 첫 값을 넣습니다.

```c
int age = 20;
double height = 172.5;
char grade = 'A';
```

`int`는 정수, `double`은 실수, `char`는 문자 한 개를 표현합니다. 같은 숫자처럼 보여도 `5 / 2`는 정수 연산이라 2이고 `5.0 / 2.0`은 2.5입니다. 자료형의 정확한 크기는 환경마다 다를 수 있어 `sizeof`로 확인합니다.

## 2. 출력 형식

`printf`의 첫 인수는 출력 형식입니다. `%d`는 `int`, `%f`는 `double`, `%c`는 문자, `%s`는 문자열에 대응합니다. `%.2f`는 소수점 둘째 자리까지 출력합니다. 형식과 실제 인수 자료형이 다르면 정의되지 않은 동작이 생길 수 있습니다.

```c
printf("age=%d height=%.1f grade=%c\n", age, height, grade);
```

## 3. 안전한 입력

`scanf`는 값을 저장해야 하므로 변수의 주소를 받습니다. `&age`는 age의 주소입니다. 반환값은 성공적으로 변환한 항목 수입니다.

```c
int age = 0;
if (scanf("%d", &age) != 1) {
    fprintf(stderr, "숫자를 입력하세요.\n");
    return 1;
}
```

`double` 입력은 `%lf`를 사용합니다. 출력의 `%f`와 혼동하지 마세요. 입력 실패 후 같은 스트림에서 다시 읽으려면 잘못된 문자를 소비하는 별도 처리가 필요하며, 지금은 오류 종료 방식으로 시작합니다.

## 4. 형 변환과 계산

서로 다른 자료형을 계산하면 변환이 일어납니다. 평균처럼 소수 결과가 필요하면 나누기 전에 하나를 `double`로 변환합니다.

```c
double average = (double)sum / count;
```

캐스팅은 잘못된 계산을 숨기는 도구가 아니라 의도한 연산 자료형을 표현하는 도구입니다.

## 따라 하기

`main.c`에서 섭씨 0, 100, -40을 입력해 결과를 확인하세요. 이후 화씨를 섭씨로 바꾸는 식 `(f - 32.0) * 5.0 / 9.0`으로 수정하세요.

## 흔한 실수와 완료 기준

- 초기화하지 않은 지역 변수를 출력한다.
- `scanf("%d", age)`처럼 `&`를 빠뜨린다.
- 정수 나눗셈 후 결과를 `double`에 저장하면 소수부가 복원된다고 생각한다.

자료형별 서식 지정자를 설명하고, 정상 입력과 문자 입력 모두에서 프로그램 동작을 예측할 수 있으면 완료입니다.
