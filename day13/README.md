# Day 13 - 구조체

학습 순서: [상세 학습](LESSON.md) → `main.c` 실습 → [문제 풀이](PROBLEMS.md)

## 목표

- 관련된 데이터를 하나의 사용자 정의 자료형으로 묶는다.
- `.`과 `->`를 구분한다.
- 구조체 배열을 함수에 전달한다.

## 핵심

문자 배열 멤버는 대입 연산자로 문자열을 받을 수 없으므로 초기화하거나 크기를 확인해 복사합니다. `typedef`는 복잡한 형식 이름을 읽기 쉽게 만들 수 있습니다.

## 연습문제

1. 도서 구조체와 출력 함수를 작성하세요.
2. 상품 배열에서 최고가 상품을 찾으세요.
3. 좌표 구조체 두 점 사이의 거리를 계산하세요.
