# Day 13 상세 학습 - 구조체로 데이터 모델링하기

## 학습 목표

서로 다른 자료형의 관련 데이터를 하나로 묶고 구조체 변수, 포인터, 배열, 함수 인터페이스를 설계합니다.

## 1. 구조체 정의와 초기화

```c
typedef struct {
    char name[32];
    int price;
    int stock;
} Product;

Product item = {"Mouse", 28000, 8};
```

각 멤버는 `item.price`처럼 접근합니다. 지정 초기화 `.price = 28000`을 사용하면 멤버 순서가 바뀌어도 의도가 분명합니다.

## 2. 구조체 포인터

포인터가 가리키는 구조체의 멤버는 `pointer->member`로 접근하며 `(*pointer).member`와 같습니다. 읽기 전용 출력 함수는 `const Product *`를 받아 불필요한 전체 구조체 복사를 피하고 변경도 막습니다.

## 3. 구조체 안의 문자열

`char name[32]`는 구조체 내부 저장 공간입니다. 초기화 이후 배열에 `=`으로 문자열을 대입할 수 없습니다. `fgets`로 직접 입력하거나 목적지 크기를 확인한 복사를 사용합니다. `char *name`은 문자 데이터 자체가 아니라 주소만 저장하므로 그 문자열의 수명과 소유권을 별도로 관리해야 합니다.

## 4. 패딩과 비교

컴파일러는 효율적인 접근을 위해 멤버 사이에 패딩을 넣을 수 있습니다. 따라서 `sizeof(Product)`가 멤버 크기의 단순 합과 다를 수 있습니다. 구조체 전체를 `memcmp`로 논리 비교하거나 그대로 영구 파일 형식으로 쓰는 것은 안전하지 않을 수 있습니다.

## 따라 하기

상품 배열에 가격 합계와 재고 가치(`price * stock`) 계산 함수를 추가하세요. 빈 배열, 긴 이름, 가격 0, 큰 재고량을 테스트하세요.

## 완료 기준

`.`과 `->`의 차이, 문자 배열 멤버와 문자 포인터 멤버의 수명 차이를 설명하고 구조체 배열을 함수로 처리할 수 있으면 완료입니다.
